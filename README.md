# Seha & Karama

A community initiative website for women's reproductive health, mental health and NCD prevention across Saudi Arabia.

## Files

- `index.html`: the whole site in one file (styles, scripts and logo included)
- `.nojekyll`: tells GitHub Pages to serve the file as is

## Publish on GitHub Pages

1. Create a new public repository on GitHub, for example `seha-karama`.
2. Upload `index.html`, `.nojekyll` and `README.md` to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then click **Save**.
5. After a minute or two the site is live at `https://<your-username>.github.io/seha-karama/`.

## Before launch

- Connect the anonymous question box to a real form (for example Google Forms). It is a preview right now.
- Replace the "Soon" audio episodes with the real recordings.
- Link "Become an Ambassador" and "Partner with us" to your sign-up form or email.
